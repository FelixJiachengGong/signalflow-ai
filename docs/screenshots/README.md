# 功能截图

本目录预留后续功能截图。以下文件尚未添加，不作为已完成的展示材料：

| 建议文件名 | 截图内容 |
| --- | --- |
| `pain-points.png` | 痛点排序、分数依据、至少一组展开的原始证据 |
| `recommendations.png` | 事实、待验证假设、建议动作、实验及验证指标 |
| `feedback-explorer.png` | 筛选后的原始反馈、来源 ID 与分页 |
| `mobile.png` | 手机宽度下的总览与反馈卡片 |

补充方式：运行 `python3 server.py`，打开本地网页，将截图保存到本目录，然后在根 README 中添加例如：

```markdown
![痛点与原始证据](docs/screenshots/pain-points.png)
```

仅在文件实际存在后添加引用。截图应保留模拟数据 / Rule-based MVP 标识，避免暗示真实用户数据、模型推理或已验证的根因。现有 `preview.jpg` 为第一版实测截图，页面版本文字后来统一为 `Phase 1 - Rule-based MVP`；截图尚未重新拍摄。
